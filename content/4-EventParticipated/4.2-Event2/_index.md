### Why I attended

I joined this FCAJ Community Day to:

- Hear real-world experiences shared by members of the FCAJ / AWS community.
- Learn presentation and teamwork skills, especially working under time pressure.
- Get access to a practical learning roadmap I could apply during my internship.

### Event highlights

- **Sharing 1 – The Ballers team:** shared their journey building a product in a short time frame (a 36-hour hackathon). Key message: focus on core features (MVP), divide work clearly, and keep communicating continuously within the team.
- **Sharing 2 – Huynh Thai Linh:** shared a practical 3-stage learning roadmap:
  - Stage 1: Build architectural thinking through **AWS Cloud Quest**.
  - Stage 2: Code and test quickly with **Floci**.
  - Stage 3: Deploy for real on an AWS **Production** environment.

### What I learned

- **Soft skills:** how to communicate information concisely in front of an audience; how to coordinate effectively as a team to meet a deadline.
- **Technical skills:** the mindset of moving from "architectural thinking" → "coding/testing" → "real deployment", rather than just clicking around the Console; how to use context engineering to work with AI more effectively.

### Application to the internship

- **Internship project:** apply the 3-stage roadmap to the URL Shortener project — understand the architecture (Lambda, DynamoDB, S3) → write code and test → deploy and operate.
- **New mindset:** always ask "who uses this?" and "what is it for?" before designing a solution; keep a fast-iterate mindset to continuously improve the product.

### Personal experience

Attending this event gave me a balanced view between deep technical knowledge and real project experience, which felt very relevant for an intern like me.

> Next steps: connect with the speakers on LinkedIn to broaden my knowledge, use the framework I learned to complete my internship report, and start practicing by building a serverless project.
